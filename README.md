# vacancies_with_db
Получение данных о компаниях и вакансиях с сайта hh.ru и отправка в БД PostgreSQL
Данный проект представляет собой систему для автоматизации работы с данными о вакансиях, предоставляемых сервисом HeadHunter. Система включает в себя:

- Модуль API для загрузки данных о вакансиях с сервиса HeadHunter.
- Управляющий модуль для создания базы данных PostgreSQL и наполнения её данными о работодателях и вакансиях.
- Утилиты для анализа собранных данных.
### Запуск проекта: 
#### Выполните следующий сценарий для старта программы:
Запустите main.py
Программа откроет интерактивное меню для работы с базой данных:
- Просмотр списка компаний и количества вакансий.
- Просмотр всех вакансий с указанием деталей.
- Расчёт средней зарплаты по всем вакансиям.
- Поиск вакансий с зарплатой выше средней.
- Поиск вакансий по определённым словам.
##  Структура проекта:
- Проект организован следующим образом: 
- main.py: Основной исполняемый файл, задаёт общую логику программы.
- config.py: Хранит настройки подключения к базе данных.
- src/api_connector.py: Отвечает за связь с API HeadHunter.
- src/utils.py: Содержит класс для работы с базой данных PostgreSQL.
## Особенности реализации:
- Принцип SOLID применён при разработке архитектуры.
- Все классы и методы документированы с пояснениями и аннотациями типов.
- Автоматически создается база данных и заполняется нужными данными.
- Интерфейс для удобной работы с базой данных через консольные команды.
## Примеры использования:
#### После запуска программы появится меню с действиями:
Привет! Добро пожаловать в программу работы с вакансиями. Выберите необходимый пункт меню:
- Получить список всех компаний и количество вакансий у каждой компании
- Получить список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию
- Получить среднюю зарплату по вакансиям
- Получить список всех вакансий, у которых зарплата выше средней по всем вакансиям
- Получить список всех вакансий, в названии которых содержатся переданные в метод слова

Выберите подходящий пункт и продолжайте работу!
